# Tarjeta de Perfil Personal

Sitio web tipo tarjeta personal para presentar información, habilidades, intereses y proyectos.

## Descripción

Este proyecto funciona como una tarjeta de presentación digital. Incluye una sección sobre el autor, habilidades, intereses, formación académica, proyectos realizados, redes y contacto.

## Secciones principales

- Sobre mí
- Habilidades
- Intereses
- Formación académica
- Proyectos
- Redes y contacto
- GitHub

## Tecnologías utilizadas

- HTML5
- CSS3
- GitHub Pages

## Objetivo

Crear una presentación personal en formato web, mostrando proyectos y habilidades relacionadas con el desarrollo web.
